### ALGO-000079: Orthogonal Vectors Hypothesis
- **Subfield:** Fine-grained and exact exponential complexity
- **Open:** Settle whether, for every fixed \(\varepsilon>0\), some constant \(c\) makes orthogonal-pair detection among \(n\) Boolean vectors of dimension \(c\log n\) require \(n^{2-\varepsilon}\) time.
- **Status:** Implied by standard SETH formulations, but not independently established. Low-dimensional variants have faster algorithms.
- **Type:** theory
- **Why:** Provides a widely reusable hardness source for similarity search and sequence problems.
- **Key works:** Williams (2005), *A New Algorithm for Optimal 2-Constraint Satisfaction and Its Implications*; Vassilevska Williams (2018).
- **Related:** Information retrieval—exact high-dimensional similarity search.
